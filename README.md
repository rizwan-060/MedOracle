# MedOracle

MedOracle is a final-year BSCS research project exploring early disease-risk prediction using machine learning, clinical calculations, medical NLP and a coordinated multi-agent workflow.

## Project structure

- `frontend/` — Flutter mobile and web application.
- `backend/` — FastAPI backend, ML pipeline and agent orchestration.
- `datasets/` — Dataset organization and metadata.
- `models/` — Model experiments and local artifacts.
- `docs/` — Architecture, research, testing and project reports.
- `scripts/` — Development and verification scripts.

## Planned technology stack

- Flutter and Dart
- Python and FastAPI
- PostgreSQL
- LangGraph
- Local LLM inference through Ollama
- Scikit-learn and other evaluated ML libraries

## Development status

Initial project structure and application setup are in progress.

## Safety and research scope

MedOracle is a research prototype, not a substitute for professional medical diagnosis or treatment. Model outputs require appropriate validation and should not be represented as clinically validated without supporting evidence.
